One satirical sentence (196 characters) roasting lawmakers who would regulate AI but cannot convert a file to PDF: the AI Safety Act orders every model to show its reasoning, yet no one in the chamber can turn the Act itself into a PDF, because its only reasoning is a chairman's comment that reads "fix later".

## Run it

```sh
node main.ts
```

The program writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset).
